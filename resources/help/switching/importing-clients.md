Upload a CSV under **Client list (CSV)** in setup step 2.

## Columns

| Column | Needed? | Also accepted as |
| --- | --- | --- |
| **Email** | Yes | Email Address, Client Email |
| **Name** | Yes, or First and Last Name | Full Name, Client Name |
| **First Name** and **Last Name** | Instead of Name | First, Last |
| **Language** | Optional (en or fr) | Locale, Lang, Langue |

Column names aren't case-sensitive. Save Excel or Google Sheets files as CSV first.

If Spotter can't find names and emails, it says so: the file needs an Email column and a Name (or First Name and Last Name) column.

## After the import

Imported clients appear on your Clients list with an **Invited** badge. Nothing is sent to them until you invite them in the last setup step, or send their invite link yourself. See [Inviting clients to the app](/help/clients/inviting-clients).

Clients already in Spotter with the same email aren't added twice.
