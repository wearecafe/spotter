## Upload program files

In setup step 2, add files under **Programs (one file per client)**:

- **Name each file after the client**, like `Maya Chen.pdf`. That's how Spotter knows whose program it is.
- PDFs and text files both work. PDFs are read automatically when that's turned on for Spotter; if it isn't, use text files.
- Up to 10 MB per file.

Choose **Import and review**. PDFs take a few seconds each, and the page updates on its own.

## How Spotter reads a program

- A line starting with **Day**, **Session** or **Workout** starts a new training day.
- A line starting with **Week 2** (or "Week 2 - Day 1 Lower") starts a new week.
- Each exercise is one line: name, sets × reps, then load and RPE if there are any. For example `Back Squat 4x5 75kg` or `Bench Press: 3 x 8-10 @ 60 kg RPE 8`.

## Review

The review page shows each client's program and a list of exercise names from your files:

- **Matched**: Spotter found the same exercise in its library, with how confident it is.
- **Needs attention**: choose **Accept** for the suggestion, **Change** to pick another, or **Create custom** to add it as your own exercise.

**Accept all suggestions** confirms every suggested match at once. Use **Spot check** to compare a client's day against the original file.

Files Spotter couldn't match to a client, or couldn't read, are flagged. Rename the file to the client's name and upload it again under **Add more program files**.

## Finish

Once every exercise name is confirmed, choose **Finish import**. Each client gets a Spotter program starting next Monday:

- The first week in the file becomes the program's weekly blueprint, ready for [progression rules](/help/programming/progression-rules).
- Any later weeks in the file keep exactly what your old platform had.
