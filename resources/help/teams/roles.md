Every coach in Spotter belongs to a team. A solo coach is a team of one. A gym has an owner and as many admins and coaches as it needs.

| | Owner | Admin | Coach |
| --- | --- | --- | --- |
| See and coach their own clients | ✓ | ✓ | ✓ |
| See and manage every client in the team | ✓ | ✓ | |
| Reassign clients between coaches | ✓ | ✓ | |
| Rename the team, invite and remove coaches, change roles | ✓ | ✓ | |
| Use and add to the shared exercise library and templates | ✓ | ✓ | ✓ |

There's one owner: the coach who started the team. The owner can't be removed. Clients see the owner's brand (name and colour) in their app.

## Change someone's role

Open **Team** and pick **Coach** or **Admin** next to their name.
