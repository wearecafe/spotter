You write reps and loads the way you'd say them. Progression rules read the numbers in them.

## Reps

| Write | Means |
| --- | --- |
| `5` | Five reps |
| `8-10` | A range. Add reps climbs from the bottom |
| `45s` | A timed hold, like a plank |
| `10/side` | Per side |
| `250m` | A distance |

## Load

| Write | Means |
| --- | --- |
| `75 kg` or `135 lb` | A load Add load can step up |
| `2 × 16 kg` | A pair of dumbbells or kettlebells |
| `Band assist` | Anything else, as a note. Add load leaves it alone |

Spotter compares kilograms and pounds correctly when checking whether a client hit the load.

## RPE

Target RPE runs from 6 to 10 in half steps. Clients pick their RPE for each set from the same scale. Leave it blank if you don't use it.

## Rest

Rest is in seconds. When the client ticks a set done, a rest timer starts with this time.
