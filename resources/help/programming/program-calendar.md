Open **Calendar** on a program to see every week of every day at a glance.

| Status | Meaning |
| --- | --- |
| **Done** | Completed by the client, or logged by a trainer. |
| **In progress** | Started but not finished. |
| **Missed** | The date has passed and it wasn't completed. |
| **Edited** | Changed by hand, so program edits skip it. |
| **Skipped · restore** | You skipped this week. Select it to put the session back. |
| **Before start** | Before the program's start date. |

Select an exercise name on the program page to see **Planned** against **Actual** for every week.
