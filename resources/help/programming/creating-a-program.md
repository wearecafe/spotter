## Start the program

1. Open the client's page.
2. Under **Programs**, enter a **name** (like "Strength block"), the **start** date, **days per week** (1 to 7) and how many **weeks** (1 to 52).
3. Choose **Create**. The program page opens.

Spotter adds the training days on sensible weekdays (for example Monday and Thursday for two days a week). Change them on the program page.

## Set up each day

For each day you can:

- Rename it (Lower A, Push, Long run…) and pick the weekday under **Every**.
- Add a **note for the client** for that day, like a warm-up or focus.
- Add exercises with **Exercise**, then search the library by name.
- Remove the day. Its upcoming sessions are removed; anything already logged stays.

Need another day? Choose **Add a training day**.

## Set each exercise

| Column | What it means |
| --- | --- |
| Sets | How many sets |
| Reps | A number (5), a range (8-10), a time (45s) or per side (10/side) |
| Start load | The load in week 1, like 75 kg or 135 lb |
| RPE | The target effort, from 6 to 10 (optional) |
| Rest s | Rest between sets, in seconds. It starts the client's rest timer |
| Each week | The progression rule: Add load, Add reps, Hold or No rule |
| Step | How much each step adds, like 2.5 kg, 5 lb or 5% |

Use the arrows to reorder exercises. Changes save as you go, and every upcoming session updates.

> **Note** When a program has already started, changes apply from the next week that hasn't been logged. The row shows "Values apply from week N".

## Change the dates

- **Starts**: move the program's start date. If sessions before the new date were already started or edited, Spotter asks you to pick an earlier date.
- **Weeks**: change the length, or choose **Add 4 weeks** to extend it.

## See what happened

Select an exercise's name to see each week's **Planned** and **Actual** numbers side by side.
