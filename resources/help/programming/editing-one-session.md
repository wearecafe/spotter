## Change one session

1. Open the session from the client's **Upcoming** list or the program calendar.
2. Change what you need: exercises, sets, reps, load, rest, notes, or the date.
3. Save.

The session is marked **Edited by hand**, and program changes skip it from now on. Everything else in the program carries on as normal.

> **Note** To change every week instead, edit the program. The session page has an **Edit program** link.

## Put it back on the program

On an edited session that hasn't been started, choose **Reset to program**. Your changes are undone and it follows the program again. Once the client has logged anything in it, it can't be reset: that would lose their work.

## Skip a session

On the client's page, remove the session from **Upcoming** with the bin icon. For a program session this skips that week instead of deleting it, so the program doesn't put it back. A skipped week doesn't count as a progression step.

To bring it back, open the program's calendar and choose **Skipped · restore**.
