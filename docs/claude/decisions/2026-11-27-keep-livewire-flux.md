# Keep Livewire and Flux rather than the pack's React and shadcn

Status: proposed
Date: 2026-11-27
Area: Stack
Decided by: Claude, at build

**Decision:** The pack's stack section assumes Inertia, React, shadcn and Wayfinder. Spotter is built on Livewire 4 single-file pages and Flux, so `CLAUDE.md` → Stack describes Spotter's stack and keeps the pack's rules that apply (self-hosted fonts, private files served through a controller, working migration rollbacks, queue jobs).

**Turned down:** Moving Spotter to the pack's React stack.

**Source:** `docs/claude/delivery-framework.md`.
